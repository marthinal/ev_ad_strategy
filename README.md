# Data-Driven Ad Strategy for EV Charging Stations

This repo centres on `data-driven-ad-strategy-for-ev.ipynb`, where I explore a Kaggle charging-session dataset to spot advertising opportunities. The notebook cleans the data, visualises usage patterns, and flags audience segments (time of day, charger type, user profile) that marketing teams can target while drivers wait to recharge.

Open the notebook in Jupyter or GitHub to walk through the analysis.
